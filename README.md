# QR Code Generator 🧾🔳

Цей простий Python-скрипт дозволяє згенерувати QR-код із тексту або посилання та зберегти його як PNG-зображення.

## 📁 Структура проєкту

```
qr-code-generator/
├── main.py              # Основний скрипт генерації QR-коду
├── qr_code.png          # Результат роботи скрипта (генерується автоматично)
└── requirements.txt     # Залежності проєкту
```

## 🧠 Як це працює

Скрипт приймає на вхід текст або посилання, генерує відповідний QR-код і зберігає його в файл `qr_code.png`. Застосовується високий рівень корекції помилок (Error Correction Level H), що дозволяє зчитувати QR навіть при частковому пошкодженні.

## ▶️ Використання

### 1. Клонуй репозиторій або завантаж файли

```bash
git clone https://github.com/Hanashiko/qr-code-generator.git
cd qr-code-generator
```

### 2. Встанови залежності

Рекомендується використовувати віртуальне середовище:

```bash
python -m venv venv
source venv/bin/activate  # або venv\\Scripts\\activate на Windows
pip install -r requirements.txt
```

### 3. Запусти скрипт

```bash
python main.py
```

Введи будь-який текст або посилання, і програма збереже QR-код у `qr_code.png`.

## 🖼️ Приклад QR-коду

QR-код буде збережений як PNG-файл у поточній директорії з назвою `qr_code.png`.
